# Trilha ABNT

Plataforma de aprendizagem gamificada para praticar normas ABNT e escrita acadêmica.

## Começar

Abra `index.html` em um navegador. A versão inicial é estática e não exige instalação ou dependências. O progresso demonstrativo fica salvo no armazenamento local do navegador.

## Estrutura

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: identidade visual e layouts responsivos.
- `app.js`: interação, busca, lição demonstrativa e progresso local.
- `favicon.svg`: ícone do projeto.

## Escopo inicial

A interface apresenta trilhas de aprendizagem, missão do dia e uma lição demonstrativa de citações. O conteúdo de normas é introdutório e deve ser revisado com fontes oficiais e orientação docente antes de ser usado como referência normativa.
